# Wordio

**Stand-up meeting leader: Vivek Singh**

### A Translation Tool
In this project I will be making an accessible and easy-to-use translator tool. International students, who make up a quarter of the student population[1], express difficulties integrating into student life due to the language barrier. This can affect their social life and their ability to connect with their peers[2]. It can also affect their academic performance and prevent them from reaching their full potential[3].
<br>
Wordio has been created with the intent to shed light on this and to encourage people to look out and talk to others who may be struggling. This applies not just to international students but to everyone.
<br><br>
In this application, users can translate between any two languages, and can also translate between Morse code and English. The language of inputted text, including Morse code, can be automatically detected and translated. A sidebar contains the user's last 10 searches which can be reinputted into the translation box. Text-to-speech allows users to hear the pronunciation of their translations in each language. Finally, a fun feature displays a language fact for each output language.
<br><br>
Wordio contains many accessible features which allow it to be used by everyone. The UI is simple and easy to use and contains contrasting colours in a light and dark theme. A few keyboard shortcuts make some functions more efficient and convenient, such as submitting the translation, opening the sidebar and swapping the languages over. Finally, the programme is compatible with screen reader softwares.
<br><br>
### Requirements
***This application uses Google Cloud's Translation API*** to translate between languages. This API was chosen for its availability, accuracy and reliability. 
<br> Users will have to ***obtain their own API key*** by creating their own Google Cloud account in order for the translation to work. This is available free of charge for a limited period of time. 
<br> This key needs to be inputted into the file ***apikey.txt***, replacing the line of X's.
